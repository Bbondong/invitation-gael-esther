# Invitations — Gaël & Esther

Générateur d'invitations personnalisées : saisissez le nom de l'invité, la civilité (M. / Mme / Couple) et la table, puis téléchargez ou partagez l'affiche en PNG. Le design de l'affiche (`affiche.jpg`) n'est jamais modifié : seuls le nom, la case cochée et la table sont écrits par-dessus.

- `index.html` : la page (aucune dépendance, aucun serveur).
- `affiche.jpg` : l'affiche de référence. Elle peut être remplacée par une version plus grande avec la même mise en page : les positions s'adaptent automatiquement.
- `DejaVuSerif-Bold.ttf` : la police de l'affiche (licence libre DejaVu).
